# AI Engineer — Learning Notes

Personal notes and research on AI Engineering concepts.

This repo is where I write up what I learn as I work through AI/ML engineering concepts, loosely following the [roadmap.sh AI Engineer path](https://roadmap.sh/ai-engineer). It's a work in progress, updated as I go.

## Why this repo

Most material on AI engineering is scattered — a paper here, a tutorial there, a course module somewhere else. This is my attempt to keep my own research and notes organized in one place: what I learned, in my own words, with links back to the sources I used.

## Structure

Notes are organized by topic, not by date — this is meant to read as a reference, not a diary.

```
├── 01-foundations/          # LLM basics, tokens, embeddings, how models work
├── 02-prompting/            # Prompt engineering, structured outputs
├── 03-apis-and-tooling/     # Working with LLM APIs, SDKs, function calling
├── 04-rag/                  # Retrieval-augmented generation, vector databases
├── 05-agents/                # Agent architectures, tool use, orchestration
├── 06-evaluation/           # Evals, testing, measuring model output quality
├── 07-frameworks/           # LangChain, LlamaIndex, and other tooling
└── resources.md              # Courses, articles, and references I'm using
```

Each topic folder has a short `README.md` summarizing what I learned, in my own words, with links to the original sources.

## Notes on approach

- Everything here is written in my own words after learning a concept, not copied from source material.
- Where a topic has a practical angle, I try to include a small example or a note on how it'd actually be used, not just the theory.
- This is a personal record of notes and research, not a tutorial or course — if you're learning AI engineering yourself, [roadmap.sh](https://roadmap.sh/ai-engineer) is a good place to start.
